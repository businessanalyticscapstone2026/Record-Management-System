REGISTERED SENIOR CITIZEN RECORDS

Import Applicant Records

Bring existing OSCA records into the system from a CSV file or searchable PDF.

Before you import
  • Imported records are saved as existing registered seniors (Completed).
  • Existing records are never overwritten. Duplicate rows are skipped and reported.
  • If no old OSCA/Application ID is supplied, the system creates a LEGACY reference for record tracking; it is not an officially issued senior citizen ID.
  • Column names do not need to match. Review and adjust the field mapping before importing. A single Full Name column is split automatically as First / Middle / Surname for review.
  • Searchable PDFs are read directly. Scanned PDFs use in-browser OCR; carefully review the extracted values before importing.

Import applicant documents

Choose a ZIP archive with one folder per applicant. Name each folder using the applicant's official OSCA ID or generated LEGACY reference.

Inside each folder, use: valid_id_front, valid_id_back, formal_photo, cedula, birth_certificate, and signature. Add the appropriate file extension (.pdf, .jpg, .jpeg, .png, or .webp). Missing documents can be uploaded later.
